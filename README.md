# Ficha Agrícola de Valoración — PWA v3

Versión orientada a inspección de campo y avalúo agrícola. Incluye:
- expediente de valoración;
- ubicación y GPS del teléfono;
- medición del cultivo;
- perfiles específicos por especie;
- muestreo;
- producción y ciclo económico;
- precios y comercialización;
- costos incurridos y pendientes;
- infraestructura;
- fotografías desde cámara/galería;
- análisis y cierre;
- guardado local, exportación JSON y CSV;
- funcionamiento offline después de la primera carga mediante service worker.

## Publicación
Subir los archivos a un repositorio de GitHub y activar GitHub Pages desde la rama principal, carpeta raíz. Abrir la URL en Chrome Android y usar "Añadir a pantalla de inicio".

## Nota profesional
La aplicación es una herramienta de captura, organización y cálculo preliminar. No sustituye la metodología del avalúo ni determina por sí sola el valor final.
